1. **프로젝트 개요**

**제안 배경**

[1] 불안한 국제 정세가 발생했을 시 핵 전쟁 위협의 증가, 대통령 관저 타겟 시 피해 범위는 서울 전역

[2] 서울 시 내에는 약 3000개의 대피소가 있으나 실질적 대피소의 기능을 하는 대피소는 미비한 실정

**제안**

핵 전쟁 위협에 대비하여 자체 설계된 지표로 서울 시 내 취약 대피소들을 군집화하여 3분 내로 대피 가능한 임시대피소와 생존성이 보장되는 생존 대피소를 제시

- 군집별 해결방안 제시
- 서울 외곽지역 최적의 대피소를 제안

**용어 정의**

[1] 임시 대피소

- 핵 공격 발발 시 인근에 있는 사람이 3~4분 내에 대피 가능한 대피소
- 서울시 내 자치구에 위치
- 도보 접근성, 취약계층, 수용인구, 방어력

[2] 생존 대피소

- 피난민들의 생존을 위한 물자가 구비되어 생존성을 보장할 수 있는 대피소
- 서울시 외곽지역에 위치 (반경 25km)
- 교통 접근성, 주변 편의시설

**2-2 데이터 수집 및 전처리**

[1] 임시대피소

- 데이터 수집
    - 전국 대피소 데이터 : 행정안전부에서 수집
    - 행정동별 격자 인구 데이터 : 격자별 인구 데이터 수집 후 행정동 위치로 조인하여 행정동 내 격자인구 집계 후 정리
    - 행정동별 취약계층 수 데이터 : 국가통계포털에서 연령별 인구_ 읍면동기준 데이터 수집 후 0~4세 및 65세 이상만 집계하여 정리
    - 건물구조 및 내진 설계 데이터 : 세움터에서 건축물대장 발급 후 해당 건축물 대장 작성 내용을 토대로 데이터 수집
- 데이터 전처리
    - 파생변수 추가
        - 거주 인구 (SUM_POP_DWE) : 대피소 반경 500m의 거주 인구를 파악하기 위해 격자의 거주인구 공간 연계 후 집계해서 생성
        - 근로 인구 (SUM_POP_WOR) : 대피소 반경 500m의 근로 인구를 파악하기 위해 격자의 근로 인구 공간 연계 후 집계해서 생성
        - 최단 거리 (nearest_distance) : 행정동의 중심점에서 대피소까지의 거리를 파악하기 Haversine Formula 공식을 사용하여 생성

[2] 생존 데이터

- 데이터 수집
    - 전국 대피소 데이터 : 행정안전부에서 수집
    - 전국 주유소 현황 위치 데이터 : 지방행정인허가데이터개방에서 수집
    - 전국 병원 위치 정보 데이터 : 지방행정인허가데이터개방에서  수집
    - 전국 대규모점포 위치 정보 데이터 : 지방행정인허가데이터개방에서 수집
    - 전국 민방위급수시설 위치 정보 데이터 : 지방행정인허가데이터개방에서 수집
    - 카카오맵 길찾기 api : 카카오맵 자동차 길찾기 api를 활용하여 출발지 대피소와 도착지 대피소 간 거리 데이터 수집
- 데이터 전처리
    - 파생변수 추가
        - 편의시설 개수 (CNT_*) : 주변 편의시설 개수를 파악하기 위해 대피소 근방 500m내 격자의 편의시설 개수 집계
        - 대피소와 편의시설 간 최단거리 (MIN_DIST_*)
    - 서울 시 반경 25km내에 있는 대피소 구분
